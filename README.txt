Easyyy_Math — пакет оновлення

Файли для розміщення ПОРУЧ із чинним firebase-config.js:
- index.html — сайт учнів
- admin.html — адмінпанель
- shared.js — спільні функції перевірки відповідей та MathJax
- style.css — спільне оформлення

Не видаляйте firebase-config.js і не змінюйте Firebase project ID.

Колекції Firestore:
- topics (поточні теми)
- users (профілі, progress, earnedStars, spentStars, inventory)
- attempts (нові спроби учнів)
- shop (магазин)
- materials (матеріали)
- settings/site (налаштування)

ВАЖЛИВО ПРО БЕЗПЕКУ:
Цей пакет — прототип для тестування, не готова захищена економіка зірочок.
Підрахунок і витрати зірочок зараз ініціює браузер. Для запуску справжнього магазину потрібні серверні Cloud Functions, перевірка правильних відповідей на сервері та суворі Firestore Security Rules.
Не робіть users/attempts загальнодоступними. Адмін має читати їх тільки через захищені правила.
Не відкривайте Firestore на запис усім користувачам. Прямі URL платних матеріалів не забезпечують захист файлів.

Історія відповідей записується лише для нових спроб. Старі помилки не відновлюються.
Для запиту attempts за uid Firebase може запропонувати створити індекс: використайте посилання в повідомленні консолі.

ПЕРЕВІРКА ПЕРЕД ПУБЛІКАЦІЄЮ:
1. Зробіть резервну копію старих файлів та Firestore.
2. Розмістіть усі 4 файли поруч із firebase-config.js.
3. Перевірте Google Authentication, правила Firestore, логарифми в MathJax.
4. Перевірте тестову тему, правильну й неправильну спробу та профіль учня.
5. До налаштування серверної перевірки не використовуйте магазин для реальних цінних винагород.
